FAQ

The important stuff.

Is Perfect Client free?

The current goal is for the core launcher to be free, local-first and not dependent on a subscription.

Does Perfect Client support Java and Bedrock?

That is the planned architecture. Java and Bedrock use separate profile types so incompatible content is not mixed together.

Is the Windows client available yet?

Not yet. This website can go live before the first Windows release. The download button can later point directly to your GitHub Release.

Are the Modrinth projects on this page real?

Yes. The Discover preview requests real public project information from Modrinth. It is only a website preview and does not install anything.

Does the website collect my Minecraft login?

No. This static website has no Microsoft password form and does not need your Minecraft account.
